# Release Checklist

Before making this repo public:

1. confirm there are no local workstation paths left
2. choose an explicit public license for the code portion
3. verify every external source link still resolves
4. confirm that no third-party dataset is redistributed accidentally
5. decide whether a tagged snapshot should match a specific article date
6. add a short disclaimer on manual data acquisition and licensing
7. review article links and series naming one more time
8. verify that generated outputs are ignored and not committed by accident
